CONFLICTS OR DECISIONS REQUIRING CONFIRMATION

1. JWT authentication is explicitly required.

   This is a major architectural decision because ARMAN owns authentication,
   password hashing, token rotation, account recovery, and OAuth integration.

2. The specification is product-scale rather than MVP-scale.

   It describes a complete ecosystem with dozens of feature domains.
   Implementation should proceed through vertical phases rather than
   attempting every feature simultaneously.

3. Fun content sources require rights and policy review.

   The prompt mentions external meme/GIF/audio sites. We should not scrape or
   redistribute content without confirming API access, licensing, attribution,
   and moderation requirements.

4. Subscriptions are listed in the database, but no monetization behavior is
   defined.

   The subscription model should not be implemented until business rules and
   a payment provider are confirmed.

5. Admin architecture is undecided.

   The specification allows either a separate admin application or a protected
   section of the website. A separate Vue admin app is cleaner for authorization
   and deployment boundaries.

6. Voice, video, Apple login, crash reporting, and some Firebase functionality
   are described as configurable or optional.

   These need explicit scope decisions before their dependencies are added.

- Group membership and moderator checks
- Profile privacy checks
- Messaging privacy checks
- Admin verification on every admin operation

API SECURITY

- Strict request validation
- Parameterized database queries
- Secure headers
- Restricted CORS
- HTTPS in production
- Consistent error codes without stack traces
- Request IDs
- Rate limiting
- Idempotency for sensitive operations where appropriate

UPLOAD SECURITY

- Server-side MIME inspection
- Extension validation
- File size limits
- Image/video/PDF validation
- Generated storage keys
- No execution of uploaded files
- Private object storage for private content
- Signed URLs
- Malware/content scanning where appropriate
- Moderation before publication

WEBSOCKET SECURITY

- Authenticate the connection
- Authorize every conversation/group subscription
- Enforce message permissions server-side
- Validate message size and type
- Rate-limit messages
- Reconnect safely
- Do not trust client-provided role data

AI SECURITY

- Provider credentials server-side only
- No secrets in Flutter, Vue, Git, logs, or assets
- Per-user usage limits
- Abuse monitoring
- Content moderation
- No private document leakage between users
